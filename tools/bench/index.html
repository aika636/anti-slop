anti-slop — стенд производительности

Меряет, сколько стоит проход ядра по чату и подвисает ли из-за этого интерфейс: главный поток, кадры requestAnimationFrame и модульный воркер. Ничего никуда не отправляется — все файлы читаются только в этой вкладке.

Если автокопирование не сработает (характерно для http без localhost), отчёт будет выделен целиком — скопируйте его вручную.
