# Изменения

Формат — по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по
[semver](https://semver.org/lang/ru/).

## 0.5.0

Первая версия, выложенная в открытый доступ.

### Изменено

- **Правило про повторы больше не опирается на блок размышлений.** Было «в размышлениях перед ответом
  сверь черновик», стало «прежде чем писать ответ, сверь задуманное». Прежняя формулировка адресовала
  инструкцию механизму, которого у половины моделей просто нет: на модели без думалки её нельзя
  выполнить в принципе. Новая работает и там, и там, а думающая модель всё равно разберёт её в
  размышлениях, потому что иначе не умеет. Английский шаблон переписан так же.
- Замер на свайпах одного сообщения (контекст побайтово одинаковый, отличается только вставка):
  новое правило на думающей модели дало падение повторов примерно вдвое. Эффект зависит от модели,
  поэтому вставка остаётся выключенной по умолчанию.

### Исправлено

- **Повторный тык по «Проанализировать чат» во время счёта** больше не запускает второй полный проход
  поверх первого. Защита была только в CSS (`pointer-events` на классе `disabled`) и умирала от любой
  темы, которая этот класс переопределит.

### Добавлено

- `LICENSE` (MIT), `CHANGELOG.md`, README для людей на русском и английском.
- `DEVELOPMENT.md` — прежний README с устройством модулей и стендами замеров.

### Убрано

- Папка `probe/` — служебное разведывательное расширение времён разработки, в релизе ему делать нечего.

## 0.4.0

### Добавлено

- **Автоподсчёт без кнопки.** Галочка и дроссель «не чаще, чем раз в N ответов». Полный проход идёт
  только там, где досчитать физически нельзя: чат открыт впервые, числа устарели после правки, свайпа
  или удаления.
- **Отбор оборотов в правило по свежести**, плитка «за последние 20 ответов» и строка «попадание
  правила» — сколько оборотов из списка встречались в последних ответах.
- **Знак темпа у оборота** — «реже», «чаще», «затих» — со сравнением по якорю.
- Автор и ссылка на репозиторий в манифесте.

## 0.3.0 и раньше
